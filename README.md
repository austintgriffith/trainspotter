# Trainspotter

A live transit map of where your machine sends data. Read-only.

## Objectives

- **Live map of your own machine.** Stops appear as your wallet and apps contact hosts.
- **Shows what leaks at each stop.** Filled in from lab captures and labelled as inferred.
- **Auditable.** One Go program, zero third-party packages, plain HTML map page. Nothing leaves the machine.
- **Easy to run on Mac, Windows and Linux.** Double-click, give permission, and the map opens in your browser.
